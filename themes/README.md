# Fluxer themes

Custom CSS themes for the Fighters Guild Fluxer server.

## RSI Blue (`rsi-blue.css`)

A Star Citizen / RSI-launcher look — deep navy surfaces, cool light text, cyan
accents.

**Apply:** Fluxer → Settings → Appearance → select the **Dark** theme → open
**Theme Studio → Quick CSS** → paste the file's contents. Changes apply live.
Hit **Share** in Theme Studio to generate a code the rest of the guild can use.

It overrides Fluxer's semantic design tokens on `.theme-dark` and keeps
`var(--saturation-factor)` in every colour, so the Saturation slider still works.
